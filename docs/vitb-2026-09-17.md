# ViT-B support validation — 2026-09-17

Validated on `gfx1151` using HRX 0.7.0 and release builds. Both model checkpoints
are pinned to the revisions documented in the README.

## Correctness

- `cargo test`: 8 CPU tests passed; GPU tests remain ignored by default.
- `cargo test --release -- --include-ignored --test-threads=1`: all 21 tests passed.
- `cargo clippy --all-targets -- -D warnings` and `cargo fmt --check` passed.
- Both architectures exceed 0.9999 all-token and CLS cosine against the independent
  F64 reference and 0.99999 single-image/batch cosine.
- Kernel checks cover erf-based GELU and all 768 LayerNorm channels, including
  partial tiles. Model checks cover descriptor masks, chunking, fixed-size summary
  rows, mixed-model graph composition, device submission, and warm replay through
  batch 64. Synthetic CPU checkpoints exercise F32/F16/BF16 packing and projection
  order without downloads.

## Warm RGB descriptor latency

The benchmark uses synthetic 224×224 RGB images and full patch masks. Each process
warms up five times, then measures 100 calls. Three runs were made for each batch
and model, with the configuration order reversed on the second repeat. The baseline
is an unchanged build of `993ed35ff2ca8c132de2623dccdafcbeb7d2eaef`.

Values below are medians of the three run medians, in milliseconds per batch.

| Batch | ViT-S+ baseline | ViT-S+ current | ViT-B current |
| ---: | ---: | ---: | ---: |
| 1 | 1.691 | 1.720 | 3.919 |
| 4 | 3.886 | 3.317 | 8.957 |
| 16 | 10.861 | 11.082 | 31.443 |

All runs reported zero downloaded bytes: descriptor outputs use mapped host-visible
storage. The before/after ViT-S+ results show no consistent regression. Run-to-run
variation is substantial (especially at larger batches), so these measurements do
not establish a speedup or a precise performance guarantee.

Reproduce a current-model measurement with:

```bash
cargo run --release --example bench_descriptors -- rgb 4 100 --variant vitb16
cargo run --release --example bench_descriptors -- rgb 4 100 --variant vits16plus
```

[Raw measurements](vitb-2026-09-17.json) include every sample and per-run p95.

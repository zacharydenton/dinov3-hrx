# DINOv3 traffic reduction — 2026-09-17

- `cls` and `patch_mean` now pool on the GPU and return only 384 floats per
  image instead of all 201 tokens. The graph uses coherent host-visible input
  and summary output storage. The result is 1,536 bytes/image versus 308,736
  bytes; the runtime records zero GPU readback-copy bytes for the new output.
  Coherent host reads still consume memory bandwidth.
- RGB normalization and patch packing share one kernel. This eliminates a
  602,112-byte normalized image allocation and its write/read round trip:
  1,204,224 bytes of intermediate traffic per image and one dispatch.
- Descriptor pooling gives CLS rows a separate workgroup path so they skip
  the 196-patch loop. Masked means retain the same arithmetic order.

The unnormalized CLS/patch-mean API contracts remain unchanged. Patch means
still divide each value before sequential accumulation, matching prior host
rounding. Prepared summary graphs are cached by batch and summary mode.

## Measurements

Identical frozen HRX 0.7.0 sources for both variants on gfx1151, batch 1,
5 warmups and 150 timed calls per run in before/after/after/before order.
The table is the median of two run medians; synchronized host latency includes
input handling and returning the result, but excludes model preparation.
Other GPU workloads were left running. [Every sample](traffic-2026-09-17.json).

| API | Before ms | After ms |
| --- | ---: | ---: |
| cls | 2.103 | 1.933 |
| mean | 2.156 | 2.001 |
| rgb | 1.974 | 1.994 |

RGB descriptor latency is effectively unchanged within observed variation;
the benefit established there is reduced traffic and intermediate storage.
Before/after outputs for all three modes are byte-identical on the benchmark
input. This does not imply throughput gains of the same size at other batches.

## Validation

The full FP64 model-reference/changing-batch suite passes. New tests compare
fused preprocessing byte-for-byte with HRX normalization plus patchification
(batch 1 and 3), and summaries exactly against full token results for three
distinct images with a two-image chunk limit and replay. Masked pooling covers
an empty mask. The compact RGB fixture has zero error. Clippy passes with
warnings denied.

```sh
cargo test --release -- --include-ignored --test-threads=1
cargo clippy --all-targets -- -D warnings
cargo run --release --example bench_descriptors -- cls 1 150
cargo run --release --example bench_descriptors -- mean 1 150
cargo run --release --example bench_descriptors -- rgb 1 150
```
